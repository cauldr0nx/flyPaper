what in this panel is real

The body is the published NeuroMechFly v2 model (Lobato-Rios et al., Nature Methods 2024; Apache-2.0) — a real Drosophila reconstructed from microscopy. It is staging, not a simulation: nothing about the pose is computed from the circuit, and the model is not spatially registered to the connectome. The text on the monitor is real: those are the log lines the run actually produced. It startles when a response clears the cutoff and is surfaced — that trigger is the run’s own decision, but the movement is invented, because nothing here models a body to compute one from. Read it as a notification. Surfacing is rare (— times in this run), so use ⇥ next surfaced to catch one.

what in this panel is real

Every point is a measured location. The α′3 synapses are the Bloom filter: each is one weight that a familiar response depresses, and the novelty score is what the MBON reads off whatever is left. A point flashes white when the current response’s tag selects the Kenyon cell that owns it, and then settles back to its own weight in the filter — so the cloud goes dark exactly where this run has learned a baseline, and stays lit where nothing has landed. The weights are the run’s own, recorded response by response, not a shimmer. How hard a response flashes is its novelty score, read against the most novel response in this run rather than against an absolute scale — almost every response on a settled scan scores a flat zero, and the highest here reaches only 0.31, so an absolute scale would show nothing at all. When one clears the cutoff and is surfaced, the cells that response lit hold an afterglow on the same envelope as the fly’s startle: one event, both panels. The calyx cloud does not respond: it is subsampled for rendering and carries no per-cell identity, so lighting it would be decoration.
